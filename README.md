# 盲選政見比較 · 2026 地方選舉

隱藏候選人的姓名、黨籍與照片，只列出**政見**與**過去做過的事**，讓選民逐條表達認同與否，最後算出最符合自己想法的候選人，再揭曉身分。

## 功能

1. **選擇選區**：依縣市、職位分組。
2. **議題重要度**：每個議題可設為 不在意／普通／重要／非常重要，作為計分權重。
3. **閱讀與評分**
   - **全盲閱讀**：每則內容都不標示是哪位候選人提出的，選區內所有項目順序打亂（每位使用者各自隨機、固定保存），避免從某則經歷認出是誰後連帶認出其他政見。
   - 分成「2026 政見」「做過的事」兩段，不混在一起，各段內依議題分組。過去政見不在閱讀頁出現。
   - 依議題、類型、關鍵字篩選，可只看尚未評分的項目。
   - 每則可選 認同／普通／不認同，再按一次取消。
4. **結果與揭曉**：候選人此時才以隨機字母（候選人 A、B、C…）呈現，與登記號次無關；顯示加權認同度排名與各議題明細，並列出各候選人過去政見的達成狀況（可展開逐則查看，不計分），確認後才揭曉姓名、黨籍、號次。

評分只存在使用者瀏覽器的 localStorage，不會上傳。
配色刻意只用灰階，避免讓人聯想到任何政黨的代表色。

## 執行

純靜態網站，不需要建置：

```bash
python3 -m http.server 8000   # 然後開啟 http://localhost:8000
```

直接用瀏覽器開 `index.html` 也可以。部署到 GitHub Pages、Cloudflare Pages、Netlify 等皆可。

## 資料格式

資料放在 `data/*.js`，在 `index.html` 引入。目前的 `data/sample.js` 是**虛構範例**。

```js
window.ELECTION_DATA = {
  meta: { title, electionDate: "2026-11-28", isSample: false, updated: "YYYY-MM-DD" },
  topics: [{ id: "transport", label: "交通" }, ...],
  races: [{
    id: "taipei-mayor", region: "臺北市", office: "市長",
    candidates: [{
      id: "c1",                                   // 任意、不具識別性的 id
      identity: { name, party, number },          // 只在揭曉時顯示
      platforms: [{ topic, title, detail, source }],  // 政見
      record:    [{ topic, text, source }],           // 過去做過的事
    }],
  }],
};
```

候選人另可加上 `past`（過去職位的政見與兌現狀況；閱讀時不顯示，開票後列在各候選人下方供參考，不計分）：

```js
past: [{
  role: "中央民意代表", period: "2016–2026", elected: true, result: "", note: "",
  promises: [{ topic, title, status, note, source }],  // status: done | partial | in_progress | not_done | unknown | not_applicable
  rates: [{ label, value, by, source }],               // 達成率、評鑑等，by 註明由誰公布（本人自述要標明）
}]
```

`source` 為選填的出處網址（所有出處都在揭曉後才顯示）（中選會選舉公報、候選人官網等）。

## 去識別化撰寫原則（重要）

隱藏名字只是第一步，政見文字本身也常洩漏身分。整理資料時請：

- **刪除**姓名、黨名、政治人物名、競選口號、「本黨」「我們團隊」這類指涉。
- **改寫成一致的中性語氣**：統一用「做什麼＋具體數字／期程／財源」的句型，避免某些候選人的文字特別有煽動性或特別簡略。
- **「做過的事」描述行為，不寫可辨識的頭銜**：寫「擔任民意代表期間提出 XX 條例修正案」，而不是「第 X 屆 XX 市議員」。
- **具體性要對等**：若某位候選人只有口號沒有細節，就照實呈現簡略內容，不替他補充。
- 每一則都附上出處，方便查核，也降低整理者主觀偏差的質疑。
- 建議由兩人以上交叉校對，確認看不出是誰。

### 已知限制

- 揭曉資訊存在前端資料檔中，懂技術的人看原始碼仍能看到；本網站的目的是「幫助自己不帶成見」，不是防止刻意查看。
- 知名候選人的招牌政見或經歷，即使去識別化仍可能被認出來。
